Bioinformatic Interface for Optimized Multi-marker Ecology

BIOME is a graphical desktop application for automated 16S and 18S rRNA amplicon analysis. It provides a DADA2-based workflow with user-defined parameters, allowing users to perform end-to-end microbiome analyses while retaining full control over read processing and downstream analyses.

User manual

Set up your project, process reads, and configure analyses using the three tabs below.

Project

Choose your marker, input files, comparison groups, and pipeline steps.

Marker
  • 16S: bacterial data; Phylum and Genus summaries. Use a DADA2-compatible SILVA training set.
  • 18S: eukaryotic data; Division and Genus summaries. Use a DADA2-formatted PR2 SSU/18S training set.

Download and select the reference database yourself. It is required for Taxonomy and Downstream analysis only.

Project files

Browse to each location or enter its path.

FASTQ folder / ZIP

Select a folder or ZIP containing paired reads in .fastq, .fq, .fastq.gz, or .fq.gz format. Each sample needs exactly one forward and one reverse file. Accepted pairs include:

Sample01_R1.fastq.gz      Sample01_R2.fastq.gz
Sample01_R1_001.fastq.gz  Sample01_R2_001.fastq.gz
Sample01_1.fq.gz          Sample01_2.fq.gz

ZIP files are extracted to extracted_fastq in the output directory; .gz files stay compressed.

Metadata file

Use a UTF-8 CSV with one row per sample, a SampleID column, and at least one grouping column. IDs must match FASTQ names without the read suffix or extension (for example, Sample01).

SampleID,Condition
Sample01,Healthy
Sample02,Healthy
Sample03,Grazed

Output folder

Each run creates a fresh analysis_<timestamp> folder containing rds, tables, figures, and logs.

Analysis settings
  • Comparison group: the metadata column defining your groups, such as Condition or Treatment.
  • Reference group: the baseline for differential abundance comparisons.
Pipeline steps

Read processing → Taxonomy → Downstream analysis

Later stages automatically include earlier ones. For Read processing alone, deselect Downstream analysis, then Taxonomy. Keep at least one stage selected and click Run selected steps.

Read processing

Set primer removal, quality filtering, and how paired reads are combined.

Primer removal
  • I know the primer sequences: enter R1 and R2 primers in 5′→3′ orientation, without spaces or direction labels. Accepted letters: ACGTRYSWKMBDHVN. BIOME handles reverse complements.
  • I only know the primer length: enter the number of bases to remove from the start of R1 and R2. Use 0 for both if primers are already removed.

Sequence-based removal uses Cutadapt. Reads without detected primers are retained unless other filters remove them; see cutadapt_primer_removal.log.

Quality truncation
  • Automatic: uses median quality profiles. Minimum quality score defaults to 30; higher values generally retain shorter, higher-quality reads.
  • Manual — Read length after primer removal (bp): enter the desired R1 and R2 lengths, excluding primer bases. Quality filtering may shorten or discard reads.
Truncation report details

See logs/trunc_len_chosen.txt. With Cutadapt, truncation positions refer to processed reads. With fixed-length trimming, positions include the removed primer bases; BIOME adds these to manual lengths internally. The report also lists retained-length targets, not measured final lengths.

Advanced filtering

Open Advanced filtering to adjust:

  • Chimera removal: Consensus (recommended), Pooled, or None. Pooled is slower and uses one thread on Windows.
  • Maximum expected errors: lower values filter more strictly; both reads must pass.
  • Maximum ambiguous bases: default 0 excludes reads containing N.
  • Minimum quality score for truncation: default 2 trims at the first base with a score of 2 or lower.
  • Remove PhiX reads: filters PhiX control sequences.
ASV length filter

All lengths are retained by default. Set both minimum and maximum lengths to keep a specific range after merging and chimera removal (for example, 250–260 bp).

Read merging
  • Merge paired reads: requires sufficient matching overlap. Defaults: 12 bp minimum overlap, 0 mismatches.
  • Concatenate reads: use when overlap is insufficient. Joins the forward and reverse-complemented reverse reads with N between them.
Experimental controls

Select the metadata column and value identifying each control type.

  • Mock community: samples with a known organism mixture; excluded from downstream analyses.
  • Negative controls: extraction or PCR blanks used for contaminant detection with decontam.
Contaminant removal outputs

When decontam runs, tables/read_tracking.csv records reads retained (decontaminated) and removed (decontam_removed) before taxonomic filtering and control exclusion.

Downstream analysis

Configure diversity tests, differential abundance, and figures. Taxonomy uses your selected reference database and marker.

Rarefaction

Equalize read depth for diversity analyses. Samples below the selected depth are excluded from these analyses.

  • Automatic: balances sample retention, richness plateau, and retained sequencing yield.
  • Minimum depth: uses the smallest sample's read count, retaining all samples.
  • Custom depth: enter a read count, such as 10,000.
Automatic settings and selection method
SettingDefaultMeaning
Maximum sample loss10%Maximum samples excluded.
Plateau gain threshold2%Maximum richness gain considered a plateau.
Minimum samples at plateau90%Required proportion of retained samples reaching a plateau.
Evaluation step size500 readsAdditional reads used to estimate richness gain; smaller steps are more precise but slower.

Candidate depths are sample read counts. BIOME maximizes depth × retained samples within the loss and plateau limits. Ties favor more samples, then greater depth. If no depth meets the plateau limit, BIOME warns and maximizes yield within the loss limit. Gains are scaled when fewer than one full read step is available.

Suggested ranges: sample loss 0–10%, plateau gain 1–2%, samples at plateau 80–95%, and step size 500–2000 reads.

Alpha diversity

Observed richness, Chao1, Shannon, and Simpson are selected by default. Pielou's evenness is optional.

Run statistical comparisons is on by default. BIOME selects ANOVA with Tukey comparisons when assumptions pass; otherwise, it uses Kruskal-Wallis with BH-adjusted Dunn comparisons.

Plots show pairwise brackets for 2–3 groups and the overall test p-value for 4 or more groups. All testable pairs are exported.

Statistical methods and output tables

Per metric, every group must pass Shapiro-Wilk normality and median-centered Levene variance tests (p > 0.05) for ANOVA. Groups with fewer than 3 or more than 5000 finite values, or constant values, use the nonparametric route. Dunn tests are two-sided, with BH correction across pairs within each metric.

Pairwise labels use adjusted p-values: **** ≤ 0.0001, *** ≤ 0.001, ** ≤ 0.01, * ≤ 0.05, ns > 0.05. Plots with 4+ groups show the raw overall p-value only.

Tables: alpha_diversity_overall.csv (including variance checks), alpha_diversity_assumptions.csv (normality), and alpha_diversity_pairwise.csv. Pairs are exported even if the overall test is nonsignificant; undefined comparisons are marked not testable.

Pielou = Shannon / ln(observed ASV richness), using rarefied counts; exported as Pielou. Values are NA for samples with at most one ASV. Comparisons require defined values in at least two groups.

Beta diversity

Choose one or more distances: Bray-Curtis (abundance), Jaccard (shared taxa), or phylogenetic weighted / unweighted UniFrac (abundance / presence–absence).

Visualize with PCoA (recommended for most datasets), NMDS, or PCA of rarefied ASV counts.

  • PERMANOVA: tests community composition differences between groups.
  • Betadisper: checks within-group dispersion before interpreting PERMANOVA.
  • Permutations: default 999; more permutations take longer.
Distance correction and diagnostics

BIOME checks PCoA eigenvalues with a relative tolerance of 10−8. Meaningful negative eigenvalues trigger square-root distances for distance-based ordination, PERMANOVA, and betadisper. PCA still uses rarefied ASV counts.

Remaining negative eigenvalues trigger a warning, without further correction. This transforms distances, not abundances. Originals are retained; analysis distances are saved as rds/dist_*_analysis.rds and diagnostics as tables/beta_distance_geometry.csv.

Differential abundance method

Choose one method. The Project tab's Reference group sets the baseline.

  • ANCOM-BC: bias-corrected analysis at Genus level.
  • DESeq2: negative binomial analysis at ASV level.
  • ALDEx2: compositional analysis at ASV level.
ANCOM-BC filtering and skipped tests

ANCOM-BC2 excludes structural zeros and taxa below 10% prevalence. With fewer than two remaining genera, the test is skipped with a warning; see differential_abundance_status.csv, ancombc_taxa_filtering.csv, and ancombc_structural_zeros.csv. Filtering and sensitivity analysis remain unchanged.

Relative abundance visualization

Select Stacked bar plots (default), Abundance heatmap, or both. At least one is required. Both use non-rarefied relative abundances.

Stacked bar plots

Taxa below 1% at Phylum/Division or 2% at Genus are grouped as Other by default. Use 0% for no grouping or higher thresholds for simpler plots.

Abundance heatmap

Choose Genus (default), Phylum (16S), or Division (18S). Top N taxa: 30 by default; range 10–100, ranked by total relative abundance, without an Other category.

Rows are taxa; columns are samples. Values are row Z-scores with hierarchical clustering and group annotations. Missing taxonomy is labeled Unclassified.

Plot output

Choose PNG, PDF, or TIFF (300 dpi) for all figures.
