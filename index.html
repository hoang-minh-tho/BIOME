Bioinformatic Interface for Optimized Multi-marker Ecology

BIOME is a graphical desktop application for automated 16S and 18S rRNA amplicon analysis. It provides a DADA2-based workflow with user-defined parameters, allowing users to perform end-to-end microbiome analyses while retaining full control over read processing and downstream analyses.

User manual

Tab 1: Project

Configure input files, experimental design groups, and allocate hardware resources.

Field / Control Options Purpose & Scientific Recommendation
Marker 16S / 18S Selects taxonomic schema (Prokaryotes vs. Microeukaryotes) and default training set.
FASTQ folder / ZIP Path / .zip Directory with paired reads (e.g. *_R1*.fastq.gz and *_R2*.fastq.gz).
Metadata file .tsv / .csv Must contain a SampleID column matching FASTQ prefixes, plus grouping columns.
Comparison group Dropdown Experimental factor to test (e.g. Group for Healthy vs Grazed vs Water).
Reference group Dropdown Baseline control level for ANCOM-BC log-fold change calculations (e.g. Healthy).
Threads Auto / Integer Sets parallel CPU cores. Auto automatically reserves $N-1$ CPU cores.

Tab 2: Read processing

Fine-tune primer trimming, automated quality truncation, DADA2 denoising, and read merging.

Parameter Default Description
Primer removal Forward and reverse sequences Trims synthetic amplification primers from 5' ends with degenerate IUPAC support.
Quality truncation Q30 (Auto) Automatically cuts read ends where median Phred score falls below Q30.
Max Expected Errors (maxEE) Fwd: 2, Rev: 2 Filters reads where expected error $EE = \sum 10^{-Q/10} > 2$. Far superior to mean Q.
Max ambiguous bases (maxN) 0 Strict requirement: DADA2 error models cannot parameterize ambiguous $N$ bases.
Chimera removal Consensus Identifies and discards PCR chimeras by evaluating sample consensus.
Minimum overlap (bp) 12 bp Minimum sequence overlap required to merge forward and reverse paired reads.

Tab 3: Downstream analysis

Perform rarefaction, alpha/beta diversity, PERMANOVA, and bias-corrected differential abundance.

Feature Options / Setting Explanation & Tips
Rarefaction strategy Automatic Plateau Finds optimal depth $N_{opt}$ balancing species saturation against sample retention.
Max sample loss (%) 10% (set to 0 for low reads) Maximum allowable sample dropout. Set to 0% if you must keep low-yield samples.
Plateau gain threshold (%) 2% (or 1%) Slope threshold defining saturation. Never set to 0% due to asymptotic curve behavior.
Beta Diversity Metrics Bray-Curtis, Jaccard, UniFrac Computes compositional or phylogenetic distance matrices for ordination.
Ordination Method PCoA / NMDS / PCA Visualizes sample clustering with 95% confidence ellipses.
Hypothesis Testing PERMANOVA + betadisper Tests group centroid separation and validates homogeneity of multivariate dispersion.
Differential Abundance ANCOM-BC Estimates sample-specific sampling fraction bias with FDR-controlled $q$-values.

Test dataset

To test BIOME immediately, you can download the 18-sample benchmark dataset from Van Phong Bay, Nha Trang, Vietnam (NCBI SRA: SRP116049 / BioProject: PRJNA399432, published in The ISME Journal).

  • Healthy corals: Acropora formosa (FOR_H), A. millepora (MIL_H), Fungia repanda (FUN).
  • Wounded / Grazed corals: Predated by corallivorous snail Drupella rugosa (FOR_G, MIL_G).
  • Biological Controls: Snail gut content (GUT) and surrounding Seawater (WAT).
