Bioinformatic Interface for Optimized Multi-marker Ecology

BIOME is a graphical desktop application for automated 16S and 18S rRNA amplicon analysis. It provides a DADA2-based workflow with user-defined parameters, allowing users to perform end-to-end microbiome analyses while retaining full control over read processing and downstream analyses.

User manual

When you open BIOME, you will see three main tabs: Project, Read processing, and Downstream analysis. This manual explains each tab and provides guidance on selecting appropriate settings for your analysis.

Project

The Project tab is where you define your inputs.

Marker

Choose 16S for bacterial 16S rRNA amplicon sequencing data. This profile applies bacterial taxonomy filtering and produces relative abundance summaries at the Phylum and Genus levels.

Choose 18S for eukaryotic 18S rRNA amplicon sequencing data. This profile applies eukaryotic taxonomy filtering and reports relative abundance at the Division and Genus levels.

Below the marker selector, BIOME displays the recommended type of taxonomy reference database for the selected marker. This is only a suggestion—the application does not download or select the database automatically.

Project files

The project requires up to four input locations:

  • FASTQ folder
  • Metadata file
  • Output folder
  • Reference database (required only for Taxonomy or Downstream analysis)

Each location can be selected with the browse button or entered manually.

FASTQ folder / ZIP

This field supplies the paired-end sequencing reads and is required for every analysis.

Select either:

  • a folder containing FASTQ files, or
  • a ZIP archive containing FASTQ files.

Supported file extensions are:

  • .fastq
  • .fq
  • .fastq.gz
  • .fq.gz

Each sample must contain exactly one forward read and one reverse read.

For example:

Sample01_R1.fastq.gz
Sample01_R2.fastq.gz

Sample01_R1_001.fastq.gz
Sample01_R2_001.fastq.gz

Sample01_1.fq.gz
Sample01_2.fq.gz

If a ZIP archive is selected, it is extracted into an extracted_fastq folder inside the analysis output directory during configuration. Compressed .gz files remain compressed because the pipeline reads them directly.

Metadata file

The metadata file contains sample information.

The file must:

  • be a UTF-8 comma-separated CSV file (.csv)
  • contain a column named exactly SampleID
  • contain at least one additional metadata column such as Condition
  • include one row for every FASTQ sample

An example is shown below.

SampleID,Condition
Sample01,Healthy
Sample02,Healthy
Sample03,Grazed

The SampleID values must match the FASTQ filenames without the read suffix or file extension.

For example,

Sample01_R1.fastq.gz
Sample01_R2.fastq.gz

correspond to

Sample01

in the metadata.

Output folder

The output folder is where BIOME stores all analysis results.

For every analysis, BIOME creates a separate folder named

analysis_<timestamp>

inside the selected location.

Each run contains four folders: rds, tables, figures, and logs. Each run calculates fresh results.

Reference database

The reference database is used to assign taxonomy to inferred ASVs. BIOME does not provide reference databases. Download a reference database yourself, then select its location in this field.

A reference database is required only when running Taxonomy or Downstream analysis. It is not needed for Read processing alone.

For 16S analyses, use a DADA2-compatible SILVA training set.

For 18S analyses, use a DADA2-formatted PR2 SSU/18S training set.

Analysis settings

Comparison group

Select the metadata column you want to use for comparing samples.

For example, if your metadata contains the columns SampleID, Location, Treatment, and Timepoint, choose the column that defines the comparison you want to make. Selecting Treatment compares samples between treatment groups, while selecting Location compares samples between sampling locations.

Reference group

The reference group defines the baseline used for differential abundance analysis.

Pipeline steps

BIOME consists of three analysis stages:

  • Read processing – Processes raw sequencing reads, including quality filtering, primer removal, denoising, read merging or concatenation, and chimera removal.
  • Taxonomy – Assigns taxonomy to ASVs and generates taxonomic summaries and relative abundance results.
  • Downstream analysis – Performs diversity analyses, statistical tests, and group comparisons.

Later stages require earlier ones. Selecting Taxonomy automatically includes Read processing, and selecting Downstream analysis automatically includes both Read processing and Taxonomy.

To run only Read processing, deselect Downstream analysis first, then deselect Taxonomy. At least one stage must remain selected.

Read processing

The Read processing tab controls how BIOME prepares sequencing reads before taxonomy assignment and downstream analysis. Here you can remove primers, trim low-quality bases, filter reads, merge paired reads, remove chimeras, filter ASVs by length, and identify experimental controls.

Primer removal

Choose one of the two primer input methods.

I know the primer sequences

Use this option if you know the PCR primer sequences.

Enter the forward primer (R1) and reverse primer (R2) in the standard 5′→3′ orientation. BIOME automatically handles reverse complements where required.

Only DNA letters are accepted:

A C G T R Y S W K M B D H V N

Do not include spaces or 5′/3′ labels.

BIOME uses Cutadapt to identify and remove primer sequences before quality filtering. Reads without detected primers are retained unless other filtering criteria remove them. Primer trimming results are recorded in cutadapt_primer_removal.log.

I only know the primer length

Use this option if you only know the primer lengths.

Enter the number of bases to remove from the beginning of the forward and reverse reads.

For example, entering 19 and 20 removes the first 19 bases from R1 and the first 20 bases from R2.

If primers have already been removed, enter 0 for both values.

Quality truncation

Quality truncation removes low-quality bases from the ends of reads. Choose either automatic or manual truncation.

Automatically determine truncation length

BIOME automatically determines suitable truncation lengths by analysing the median quality profiles of multiple sequencing files.

The only required parameter is Minimum quality score, which defaults to 30.

Higher values produce shorter, higher-quality reads. Lower values retain more sequence but may reduce read quality.

The selected truncation lengths are saved in trunc_len_chosen.txt.

Manually specify truncation length

Alternatively, you can choose the truncation lengths yourself after inspecting the quality profile plots.

Advanced filtering

Click Advanced filtering to display additional quality filters.

These settings include:

  • Chimera removal method
  • Maximum expected errors
  • Maximum ambiguous bases
  • Minimum quality score for truncation
  • Remove PhiX reads

Chimera removal method

A chimera is an artificial sequence produced during PCR.

BIOME provides three methods:

  • Consensus (recommended)
  • Pooled
  • None

Consensus performs well for most datasets and supports multithreading. Pooled is slower and uses a single processing thread on Windows.

Maximum expected errors

Expected errors estimate sequencing quality using base-quality scores rather than known mismatches.

Lower values apply stricter filtering.

Forward and reverse reads must both pass this filter.

Maximum ambiguous bases

The default value of 0 removes reads containing ambiguous base calls (N).

Minimum quality score for truncation (default 2) follows DADA2's default setting and truncates reads at the first base with a quality score of 2 or lower.

ASV length filter

This filter is applied after read merging and chimera removal.

By default, all ASV lengths are retained.

To filter ASVs, specify both a minimum and maximum sequence length. Only ASVs within this range are kept.

For example, entering 250–260 bp retains sequences between 250 and 260 bp.

Read merging

Choose how paired-end reads are combined.

Merge paired reads

Forward and reverse reads are merged using their overlapping sequence.

Additional settings control:

  • Minimum overlap (default 12 bp)
  • Maximum mismatches (default 0)

Successful merging requires both sufficient overlap and matching sequences.

Concatenate reads

Concatenation joins the forward read and the reverse-complemented reverse read, inserting N letter between them instead of merging overlapping sequences.

Use this option when read overlap is insufficient for merging.

Experimental controls

Experimental controls are identified using metadata

Mock community

Mock communities contain a known mixture of organisms.

Select the metadata column and value that identify mock samples.

Mock samples are automatically excluded from downstream analyses.

Negative controls

Negative controls, such as extraction blanks or PCR blanks, are used for contaminant detection with decontam.

Select the metadata column and value that identify negative controls.

Downstream analysis

The Downstream analysis tab contains the settings for taxonomic summarization, diversity analyses, statistical testing, differential abundance analysis, and publication-ready visualizations.

Taxonomy

Taxonomy is assigned using the selected DADA2-compatible reference database and marker profile.

Rarefaction

Rarefaction equalizes sequencing depth across samples before calculating diversity metrics.

Choose one of the three modes below.

Automatic

Automatic rarefaction evaluates the sample read counts as candidate depths. The maximum sample loss setting excludes depths that remove too many samples (default: 10%, retaining at least 90% of samples).

For each remaining depth, BIOME estimates the increase in ASV richness with an additional read step (default: 1,000 reads). A sample is considered to have reached a plateau if the estimated richness gain is no greater than the plateau gain threshold (default: 2%). If fewer than 1,000 additional reads are available, the gain is scaled accordingly.

The minimum samples reaching plateau setting specifies the proportion of retained samples that must reach a plateau (default: 90%). BIOME then selects the depth that retains the most samples while satisfying both the sample-loss and plateau criteria. If no depth qualifies, BIOME issues a warning and uses the lowest observed sample depth.

Advanced automatic settings

These settings determine how conservative the automatic selection will be.

ParameterRecommendedMeaning
Maximum sample loss (%)0−10%Maximum percentage of samples that may be excluded when selecting a depth.
Plateau gain threshold (%)1−2%Additional richness considered small enough to indicate a plateau. Smaller values require a flatter rarefaction curve.
Minimum samples at plateau (%)80−95%Higher values require more retained samples to reach a plateau.
Evaluation step size (reads)500−2000Number of reads added when assessing the rarefaction curve. Smaller values are more precise but slower.

Minimum depth

Rarefies every sample to the sequencing depth of the smallest sample.

This retains all samples but may use a shallow sequencing depth.

Custom depth

Enter your own rarefaction depth.

For example,

10000

rarefies all retained samples to 10,000 reads.

Samples with fewer reads than the selected depth are excluded from diversity analyses.

Beta diversity

Beta diversity measures differences in microbial community composition between samples.

Metrics

Choose one or more distance metrics.

MetricDescription
Bray-CurtisDifferences based on taxon abundance.
Weighted UniFracPhylogenetic distance weighted by abundance.
Unweighted UniFracPhylogenetic distance based on presence or absence.
JaccardCommunity dissimilarity based on shared taxa.

Ordination

Choose how beta diversity is visualized.

MethodDescription
PCoAPrincipal Coordinates Analysis. Recommended for most datasets.
NMDSNon-metric Multidimensional Scaling. Useful for complex ecological data.
PCAPrincipal Component Analysis of rarefied ASV counts.
Statistics

These settings control the statistical tests used for beta diversity.

Run PERMANOVA Tests whether microbial community composition differs between groups.

Run betadisper before PERMANOVA Tests whether within-group variation is similar before interpreting PERMANOVA.

Permutations (default: 999)Number of random permutations used to calculate p-values. Higher values increase accuracy but also increase analysis time.

Alpha diversity

Alpha diversity is calculated automatically using:

  • Observed richness
  • Chao1
  • Shannon
  • Simpson
Differential abundance method

Choose one differential abundance method.

MethodRecommended use
ANCOM-BCBias-corrected differential abundance analysis at the genus level.
DESeq2Negative binomial differential abundance analysis at the ASV level.
ALDEx2Compositional differential abundance analysis at the ASV level.

The selected Reference group is used as the baseline for fold-change calculations.

Relative abundance plots

These settings simplify stacked bar plots by grouping low-abundance taxa into Others.

Choosing a threshold

  • 0% – No grouping.
  • 1–2% – Light grouping.
  • 3–5% – More grouping for cleaner plots.
Plot output

Figure format

Select the output format for all figures. Available formats are PNG and PDF.
